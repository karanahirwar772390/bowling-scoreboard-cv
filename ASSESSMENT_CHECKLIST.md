# Submission Checklist

## GitHub
- [ ] Create GitHub repository.
- [ ] Upload `src/`, `app.py`, `run.py`, `extract_screenshots.py`.
- [ ] Upload `README.md` and `requirements.txt`.
- [ ] Do NOT upload a huge video unless allowed; keep the assessment video local.
- [ ] Add a `.gitignore`.

## Demo
- [ ] Open Streamlit app.
- [ ] Upload `bowling_scoreboard.mp4`.
- [ ] Show input video.
- [ ] Click Extract Scoreboard.
- [ ] Show detected/extracted data.
- [ ] Screen-record the complete flow in one video.

## PDF
- [ ] Candidate name.
- [ ] Problem statement.
- [ ] Architecture diagram.
- [ ] Input-frame screenshot.
- [ ] Detection screenshot.
- [ ] OCR/output screenshot.
- [ ] Final JSON.
- [ ] Short explanation of design decisions and limitations.
